# История версий

## 1.0.0 — 24 октября 2026

- Отдельные контейнеры фронтенда, бэкенда и PostgreSQL в общей сети Compose.
- Проверки готовности сервисов и сохранение данных БД в именованном томе.
- Запуск одной командой или файлом `start.command` на macOS.
- Docker Registry и запуск опубликованных образов без исходников.
- Ansible для установки Docker, настройки GitHub SSH и получения проекта.
- Общая версия релиза в `VERSION`, тег Git `v1.0.0` и теги образов `1.0.0`.
